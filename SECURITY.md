# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately. Don't open a public issue, discussion or pull request.

Use GitHub's private vulnerability reporting: on this repo's **Security** tab, choose **Report a vulnerability**.

Please include:

- the SDK version and the iOS and Xcode versions you used
- what the issue is and what an attacker could do with it
- steps to reproduce it, or a proof of concept
- any suggested fix

Never include real payer data, card numbers, tokens or merchant keys. Use dummy values.

SYNQT acknowledges reports within a few working days and keeps you informed while we investigate and fix the issue.

## Supported versions

| Version | Supported |
|---|---|
| Latest 0.x release | Yes |
| Older releases | No |
